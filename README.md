# Dashboard de Finanzas Personales

Aplicación web interactiva para el registro y control de ingresos y gastos personales, con cálculo automático de balances, filtrado dinámico y visualización de datos en tiempo real.

## Características Principales
* **Gestión de Transacciones:** Registro y eliminación de ingresos y gastos clasificados por categoría.
* **Cálculo en Tiempo Real:** Actualización automática del Balance Total, Ingresos Totales y Gastos Totales.
* **Visualización de Datos:** Gráfica interactiva tipo dona generada con **Chart.js** que agrupa los gastos por categoría.
* **Filtrado Dinámico:** Vista rápida de todos los movimientos, solo ingresos o solo gastos.
* **Persistencia Local:** Almacenamiento de datos en el navegador mediante `localStorage`, manteniendo el historial intacto entre sesiones sin necesidad de servidor.
* **Diseño Responsivo:** Interfaz adaptable a computadoras y dispositivos móviles mediante CSS Grid y Flexbox.

## Tecnologías Utilizadas
* **HTML5** (Estructura semántica y Canvas)
* **CSS3** (Variables CSS, CSS Grid, Flexbox, Diseño Responsivo)
* **JavaScript (ES6+)** (Manipulación del DOM, métodos funcionales `filter`, `reduce`, `forEach`, `localStorage`)
* **Chart.js** (Renderizado de gráficos dinámicos)
